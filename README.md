# Hangman Game 🎮

A simple command-line Hangman game written in Python.

## How to Play

Run the script and guess letters one at a time to reveal the hidden word before running out of attempts.

```bash
python hangman.py
```

## Rules

- You have 6 incorrect attempts before the game ends.
- Each wrong guess draws another part of the hangman.
- Guess the full word to win!

## Words

The game picks a random word from a small built-in word list (animals).
